# Zentra Desktop Client

Official distribution repository for Zentra.

## Download
Download the latest official installer and updates from the [Releases](https://github.com/Zenith-Zentra/App-Zentra/releases) page.

- **Installer:** `Zentra-win-Setup.exe`
- **Direct Portable:** `Zentra-Direct.exe` or `Zentra-win-Portable.zip`

## Updates
Updates are automatically delivered to the desktop client via Velopack.
